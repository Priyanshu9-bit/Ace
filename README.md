# Ace (Gadhaa - Odia Card Game)

A real-time multiplayer card game for Gadhaa (Donkey / Bhabhi Thulla) featuring live voice chat, spectator mode, and Pro AI computer opponents.

## Features
- **Real-Time Multiplayer**: Instant room creation, short room codes, and live multiplayer synchronization.
- **Play with Computer**: Play offline or practice with 1, 2, or 3 Pro computer bots.
- **Pro Bot AI**: Features full-deck card counting, void tracking, boss cashing, and multi-cut finishers.
- **Voice Chat**: Built-in WebRTC voice communication and safe player mentorship.
- **Multi-Language**: Full English and Odia (ଓଡ଼ିଆ) translations.

## Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test
```
