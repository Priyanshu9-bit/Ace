# Android APK Downloads

Place your compiled `gadhaa.apk` in this folder (`client/public/downloads/gadhaa.apk`).
When present, users visiting `/download/apk` or clicking "Download APK" on the site will directly download this `.apk` file!
If no file is present, the server automatically redirects visitors to the latest GitHub Releases page:
https://github.com/Priyanshu9-bit/Ace/releases
